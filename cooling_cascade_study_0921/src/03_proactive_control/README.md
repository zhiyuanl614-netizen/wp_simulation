# P6 —— 主动控制线性规划（对齐参照文献方法）

**定位：** 按参照文献 **Yu, Guo, Wu, Qiao, Sun.《Early warning and proactive control strategies for power blackouts caused by gas network malfunctions》, Nature Communications 15:4714 (2024)（孙宏斌院士团队）** 的方法，把本项目的"水-电早期预警"与该文献的"气-电早期预警"**逐项对齐**：物理量由天然气替换为冷却水，主动/被动运行逻辑、预警指标、控制策略、优化方法完全对应。

## 物理量类比（气 → 水）

| 文献（气-电） | 本项目（水-电） |
|---|---|
| 气网管道故障 + 阀室隔离 | 市政供水压头 < 28 m 失效 |
| 终端区管存气 (line pack, LP) | 补水箱 + 集水池储水 |
| 进气压力 → 低压保护跳机 | 凝汽器背压 → 高背压/跳泵保护 |
| ALP 可用管存 (Available Line Pack) | **ASW 可用储水量 (Available Stored Water)** |
| AET 可用逃逸时间 (Available Escape Time) | AET 可用逃逸时间（跳机前剩余时间）|
| SAET 静态可用逃逸时间 | SAET 静态可用逃逸时间（初始缓冲窗口）|
| 气调中心 GDC → 电力控制中心 EPCC | 市政供水 ICS → 电力系统 ICS |
| 受影响燃气轮机降出力 + 其余机组顶上 | 受影响机组 runback + 其余机组顶上 |

## 与文献一致的三项对齐（本次新增）

1. **早期预警指标形式化**（`warning_indicators.py`）：AET / ASW / SAET，由 P1 水力-热力模型前向积分计算。
2. **主动控制线性规划**（`proactive_lp.py`）：目标 = 最小化控制期总能量缺额；约束含功率平衡、机组容量、**爬坡率**、**直流潮流(PTDF)**、失效机组末端出力为零。
3. **PA / SP / DP 三策略**（`run_p6.py`，对齐文献 Fig.6）：
   - **PA 被动控制**：备用只在受影响机组**跳机后**才动作（因果约束）。
   - **SP 静态主动控制**：控制时间 T_i = SAET_i，在静态逃逸时间内将受影响机组降到零。
   - **DP 动态主动控制**：迭代延长 T_i（用 AET 在 T_set=α·T_i 处重算），动用更多备用+储水。

## 方案选择（依据研究者确认）

- **潮流方法**：**方案 B —— 全流程直流潮流 (DC-PF / PTDF)**，与文献一致（快、必收敛、适合 LP）。
- **备用体系**：**两级（旋转备用 + 慢起机备用）**，与文献一致。
- **命名**：ALP 的水侧类比统一为 **ASW（Available Stored Water 可用储水量）**。

## 结果（同源 6 机共因 CO: 母线 89/80/10/66/65/26，2,631 MW，300 min 时域）

| 策略 | 最大功率缺额 | 总能量缺额 | 最大线路过载 |
|---|---|---|---|
| **PA 被动** | 334.9 MW | 59.6 MWh | 165.8 MW |
| **SP 静态主动** | **0.0 MW** | **0.0 MWh** | 36.8 MW |
| **DP 动态主动** | **0.0 MW** | **0.0 MWh** | 36.8 MW |

早期预警指标（规范校准后）：SAET(89/80/10/66/65/26) = 88.6 / 116.9 / 124.8 / 145.6 / 146.0 / 185.5 min；ASW0 = 2773–2970 m³。

**关键结论（与文献一致）：**
1. **主动控制完全消除功率缺额**——PA 被动造成 334.9 MW 峰值缺额（双脉冲：89/80 簇 ~85–105 min、10/66 簇 ~118–130 min）、59.6 MWh 损失电量；早期预警使备用有充足时间（SAET 88.6–185.5 min）提前爬坡，SP/DP 均将缺额降为 0（此场景窗口充裕，DP 与 SP 同效）。
2. **软着陆机制**——受影响机组在预警后**逐步降出力**（Fig.10），其余机组在缺额发生前**提前爬坡顶上**；被动则等跳机后才响应，反应不及导致深缺额。
3. **规范校准的影响**——按 GB/T 50102/DL/T 5339 校准冷却水系统后，SAET 延长至约 1.5–3 h，预警窗口更充裕。
4. **潮流方法统一为 DC**——与文献一致，LP 中用 PTDF 表达线路潮流约束；过载以松弛变量惩罚项体现。

## N-k 稳健性与全序级联（`nk_scan.py` / `full_order_cascade.py`）

- **SP 对所有 k 零缺额（24/24）**：k=1–6 全枚举×4 子集，警告驱动软着陆对最多 6 台全耦合集合（失 2,631 MW）均成立，失效规模轴上**不存在临界规模 k\***。
- **被动地板与饱和**：最坏子集 PA 峰值 k=1 为 91.1 MW，k≥2 饱和于 146–155 MW；能量缺额 7.6 → 12.2–12.9 MWh 饱和——受其余机组爬坡与网络输送上限封顶，与损失量（607→2,631 MW）解耦。
- **全序级联（B-RT 6 事件，35.0–38.1 h）**：200 min 合并窗内归并为**单簇**（T0=33.5 h，失 2,631 MW）：簇内联合 LP PA 134.8 MW/11.2 MWh、SP 0/0；同时上界 SIM 134.8/11.2（单簇下 SEQ≈SIM）；逐事件求和下界 SUM 仅 8.6 MW/0.7 MWh（单机分解低估 ~16×）。
- **临界降出力速率（不变量）**：r\* = 0.545 %P_g/min（1/11000 s），T_max = 183.3 min = 2.07×SAET。

## 取水节点位置的敏感性（`node_sensitivity.py`）

**背景疑问：** 不同 junction 节点在市政水源停供后失压时刻差异极大（见 `src/00_muni_wdn/saet_distribution.py`：全网 P10/P50/P90 = 3.8/9.8/17.0 h，28% 节点长时间不失压），故"选哪个节点为电厂供冷却水"会改变"开始影响机组的时刻"。本模块把该疑问贯通到电力影响。

**两级缓冲（关键区分）：**
- **市政级**：水源停供 → 取水节点跌破 28 m，时长 `t_muni(节点)`，**强依赖节点位置**（小时级）。
- **冷却级**：取水失效 → 机组跳机，时长 = 冷却 SAET(88.6–185.5 min)，**电厂内部属性，与节点无关**。

**两种取水布置对比（六厂 89/80/10/66/65/26，联合 LP，780 min 时域）：**

| 布置 | 市政偏移 τ | PA 峰值缺额 | PA 能量缺额 | SP/DP 最大缺额 |
|---|---|---|---|---|
| **CO 同源同位置**（危机同时）| [0,0,0,0,0,0] h | 334.9 MW | 59.6 MWh | 0 / 0 |
| **DISP 指定分散取水**（B-ST 真实错峰）| [0, 0.5, 2.5, 2.5, 5.75, 7.75] h | **334.9 MW**（Δ=0%）| **43.7 MWh**（−26.6%）| 0 / 0 |

**机理结论：**
1. **错峰削能量、不削峰**：六取水点同处一个分区（DMA1），前两机 89/80 的 τ 仅差 0.5 h、危机窗口完全重叠，首共因簇钉住峰值（334.9 MW 不变）；后续事件时间隔离使备用得以在其间回填，能量缺额削减 26.6%（59.6→43.7 MWh）。
2. **主动(SP/DP) 对取水位置稳健**：各机组自其市政失压时刻起有**冷却 SAET 窗口**做软着陆（窗口与节点无关），逐台均可消除缺额——市政失压的先后只是把危机在时间轴上平移/错开，不改变"每台机组可被主动救回"这一结论。

**方法（物理正确且计算可行）：** CO 与 DISP 均用**联合 LP**（780 min 时域、5 min 时步、DC-PTDF、共享备用）求解，DISP 偏移经 `proactive_lp.py` 的 `muni_offset_min` 参数注入（各机组市政失压偏移；默认全 0 即同时故障行为，不影响 `run_p6.py`）。

## 备用爬坡率 R 扫描（`ramp_rate_scan.py`）

**背景疑问（审阅指导 P1-1）：** SP 可行性对其余机组备用爬坡率 R 的敏感性如何？是否存在"R 减半 → SP 缺额转正"的相变点？k≥3 的 SP 残留缺额是爬坡驱动还是网络/备用驱动？扫描严格复用 `proactive_lp.ProactiveLP`（300 min 时域/5 min 时步/DC-PTDF/备用上限＝物理余量），**仅 `ramp_frac_per_min` 为变量**；R∈{0.0025–0.04}·Pmax/min 共 9 点；三场景＝S1 单机 bus89（607 MW）、S2 CO 六台 89/80/10/66/65/26（2,631 MW）、S3 N-k worst k=3 {89,80,10}（1,534 MW）。R＝0.01/0.02 处 10 项锚点与 `run_p6`/`nk_scan` 既定结果**逐位一致**。

**三点结论（图 14 / 论文表 7）：**
1. **单机：SP 对 R 完全稳健**——R 低至 0.0025/min（既定值 1/4）仍全程零缺额；"R 减半→SP 转正"在单机场景不成立。PA 随 R 单调改善（能量 196.1→35.9 MWh、峰值 474.2→315.0 MW，R 0.0025→0.01；R=0.04 时 PA 亦归零）。
2. **CO 六机：SP 相变点 R\*∈(0.0035, 0.005]**——R＝0.005（减半）仍零缺额，0.0035 起转正并急剧放大（6.4→144.0→557.7 MWh）；PA 更敏感（@0.0025 达 1,368.0 MWh、峰值 1,087.1 MW，为 @0.01 的 23 倍）。
3. **k=3：残差纯爬坡驱动**——S3 相变区间与 CO 重合（R\*∈(0.0035, 0.005]，5.9→42.0→137.9 MWh 放大），量级介于单机与 CO 之间，与 1,534 MW 规模一致。含平衡机 bus69 的子集（如 {69,80,89}）会出现 R 不敏感的 57.12 MW 稳态地板，但那是平衡机重指派强迫潮流重分布的伪影，并非网络输送上限的普遍性质，指定总体（不含 69）下不出现。

## DP 差异化 + 备用容量扫描（`dp_reserve_scan.py`）

**背景（P1-3 首选方案 + P1-2 LP 侧）：** R 扫描造出了"SP 有残差且系爬坡驱动"的困难区域（低 R 的 CO），使 DP vs SP 差异化可解；同时补齐 LP 备用容量轴 reserve_frac（`rest_cap = Pg0 + rf×(Pmax−Pg0)`）。链路口径与 `ramp_rate_scan.py` 完全一致，仅 mode/T_ctrl/reserve_frac 为变量；DP@0.01 对齐 run_p6、rf＝1.0 与 R 扫描 R＝0.01 列逐位一致（8 项锚点）。

**结论（图 14 DP 曲线 / 论文表 7 DP 列、表 8）：**
1. **DP 差异化恰在爬坡受限区**：CO 相变点由 R\*∈(0.0035, 0.005] 下移至 R\*\_DP∈(0.0025, 0.003]（区间中点之比 ≈0.65≈1/α）；低 R 区 DP 残差远小于 SP——@0.0025 CO 为 2.8 vs 557.7 MWh（削减 99.5%）、k=3 为 3.7 vs 137.9 MWh（削减 97.3%）；单机 DP≡SP 全零。窗口充足时 DP 与 SP 合同（`run_p6` 观察）的条件边界由此划定：R≲0.003 的爬坡受限区 DP 才与 SP 分离。
2. **备用容量轴 rf\***（R=0.01 固定，rf∈{1.0, 0.5, 0.35, 0.25}；rf=1.0 行与 R 扫描 0.01 列逐位一致）：单机 SP 稳健至 rf＝0.25；**CO 相变 rf\*∈(0.5, 1.0]**（rf=0.5 时 103.1 MWh，0.35/0.25 时 2,344.9/4,228.0 MWh，容量型与爬坡型缺额复合）；**k=3 相变 rf\*∈(0.35, 0.5]**（0.35 时 160.8、0.25 时 1,213.8 MWh），介于单机与 CO 之间。主动控制可行性边界由**爬坡率×备用容量联合**决定，任一轴单独充裕不充分。

## 与文献的差异说明
- 文献用真实浙江省耦合系统 + 气网动态水力(FDTD/Weymouth)；本项目用 IEEE-118 + 解析冷却水水力模型。
- 文献 DP 用严格迭代算法(Table 2)；本项目 DP 用 T_set=α·SAET 的单次延长近似（可扩展为完整迭代）。
