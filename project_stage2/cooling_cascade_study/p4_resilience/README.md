# P4 — 早期预警的系统韧性量化（核心研究目标）

**研究目标（本项目的最终科学问题）：**
利用**水力慢动态（分钟级缓冲）与电力快动态（秒级）之间的时序差异**，当市政水网故障发生后，经**信息/工业控制系统（ICS）将故障信息提前预警**给电力系统，使其**主动**（跳机前）做出调整，而非**被动**（跳机后）响应。通过预警前后的对比，**量化系统韧性的优化**。

## 核心机制

```
市政水网故障
   │
   ├─(慢, 分钟级)→ 水力: 补水箱/集水池水位缓降 → 循环水泵流量下降 → 背压上升 → 机组跳机
   │                └──────────── 缓冲时间 t_buffer (≈20 min) ────────────┘
   │
   └─(快, 秒级, 经 ICS 预警)→ 电力: 立即启动三级备用(燃机/水电/停机备用)
                              在机组跳机前把备用"预置就位"
```

**关键洞察：** 受影响机组总容量常**大于系统旋转备用**，仅靠旋转备用不足以承受多机共因跳闸 → 被动响应必然深跌。而三级备用**起机需要时间**（~15 min）——恰好可利用水力缓冲提供的预警窗口提前启动，使跳机时刻备用已就位。**预警提前量 = 跳机时刻 − 预警时刻，直接决定跳机时可用备用量，从而决定韧性。**

> **注（v2 水力模型）：** 因损失已改为随热负荷变化（见 `models/water_side_model.md` 2b 节），机组降额时热负荷下降、集水池排水变慢，**共因机组的跳机被自然拉开**（3 机从 ~4.5 min 拉到 ~11 min）。这一自保护负反馈使 3 机共因故障即使被动也基本安全（49.5 Hz），**危险阈值上移至 5 机共因**。故 P4 演示改以 **5 机共因**为代表危险场景。

## P4 核心结果（同源 5 机共因故障：母线 89/80/10/66/65）

### 被动 vs 主动预警（主动 = 预置三级备用 + 速率受限 runback + 15% 预防性切负荷）

| 韧性指标 | 被动响应 | 主动预警 | 增益 |
|---|---|---|---|
| 频率最低点 | **41.73 Hz** | **49.23 Hz** | **+7.50 Hz** |
| 韧性裕度 (f−47Hz) | −5.27 Hz（崩溃）| +2.23 Hz（安全）| **由崩溃转为安全** |
| 跳机台数 | 5 | 0（runback 保住机组）| ✅ 避免连锁跳机 |
| 是否触发欠频崩溃 | 是 | 否 | ✅ 避免 |

**结论：早期预警把一次频率崩溃（41.7 Hz）转化为可控事件（49.2 Hz），韧性增益 +7.5 Hz。**

> **重要物理约束（v2 修正）：** 主动降负荷（runback）卸下发电的速率**不能快于备用/切负荷的补充速率**，否则会自造缺额、适得其反。模型已将 runback 速率上限约束为三级备用起机速率——这是一条有工程意义的结论：**"软着陆"必须节奏匹配，而非快速甩负荷。** 对 5 机这类大规模缺额（2317 MW ≫ 旋转+三级备用 ~900 MW），**预防性切负荷是不可或缺的第二杠杆**。

### 敏感性（核心结论）

1. **预警提前量 → 韧性（右图）：** 存在明显"拐点"——预警提前量 ≥ ~5 min 时，三级备用有充足时间起机，频率稳定在 49.35 Hz；当提前量缩小到 ~2 min 以下，备用来不及就位，频率跌至 48.4→46.9 Hz。**这直接证明：水力缓冲窗口越长、预警越早，韧性越高；预警若太晚则失去价值。**

2. **三级备用起机速率 → 韧性（左图）：** 起机越快，同样预警窗口内能就位的备用越多，频率越高（起机速率 0.3×→2.0× 对应 43.9→50.0 Hz）。说明韧性由"**预警提前量 × 备用起机能力**"共同决定。

## 韧性量化框架（可推广）

本阶段确立了以"**频率韧性裕度 = f_nadir − 崩溃阈值**"为核心的量化指标，并可扩展：
- ΔResilience = f_nadir(主动) − f_nadir(被动)
- 临界预警提前量 t_lead* ：使 f_nadir 恰好 ≥ 安全阈值的最小提前量（本例 ~2–5 min）
- 结合失负荷量、级联跳线数、母线电压跌落，构成多维韧性向量。

## 局限与后续
- **QSS + 简化频率模型**：频率用"缺额 vs 分级备用（旋转/三级）"的准稳态平衡刻画，捕捉了"速率/提前量竞赛"的一阶机理，但非逐周波机电暂态；RoCoF、暂态摇摆需 ANDES/PSS-E RMS 增强。
- **备用参数**（三级备用容量 900 MW、起机 ~15 min）为典型假设，绝对量值供参考，**相对趋势与拐点结论稳健**。
- **预警可靠性未建模**：实际 ICS 预警存在漏报/误报/时延不确定，后续可加入预警置信度对韧性增益的折减。
- **后续 P5**：结合 `scenarios/scenario_matrix.csv` 做全场景扫描，绘制"预警提前量 × 故障规模"的**韧性图谱**，并给出面向调度的预警-处置最优策略。
