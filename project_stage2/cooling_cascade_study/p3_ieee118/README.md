# P3 — IEEE 118 全系统级联仿真

**阶段目标：** 把 P1 的"水力–热力子模型"作为受影响机组的**功率降额/跳机信号源**，接入 **IEEE 118 交流网络**，考察真实网络的**潮流转移、母线电压、频率响应与线路过载级联**。

## 方法

采用**准稳态（QSS）交流潮流 + 过载跳线迭代**的级联分析框架（电网级联筛查的通行做法）。每个宏观时步：

1. **P1 子模型推进**每台受影响机组：水位→循环水流量→背压→降额系数 k_p→高背压跳机（复用 `p1_smib/`）。
2. **一次调频再调度**：受影响机组损失量 → 系统其余在运机组按调差 R 与旋转备用（受 Pmax 物理余量约束）分担 → 准稳态 COI 频率偏差。
3. **交流潮流**（PYPOWER `runpf`）求解网络稳态 → 支路潮流/负载率、母线电压。
4. **过载级联**：负载率 > 阈值的线路逐条跳闸并重解潮流，直至无过载或**潮流不收敛（系统解列）**。

> 线路热稳定限值：case118 原值为占位（9900 MVA），本研究按 `rate = max(1.5×基准潮流, 50 MW)` 派生，使基准态安全（最大负载率约 0.67）。

## 运行

```bash
cd p3_ieee118
python run_p3.py --affected 89            --t_fault 60 --ramp 0            # 单机
python run_p3.py --affected 89,80,10      --t_fault 60 --ramp 0            # 同源多机共因
python run_p3.py --affected 89 --no_overload                              # 关过载跳线(隔离频率/电压效应)
python run_p3.py --affected 89 --overload_margin 0.6                      # 收紧限值放大级联
python plot_p3.py
```

## P3 初步结果

| 场景 | 过载跳线 | 频率最低点 | 最低电压 | 级联跳线 | 结局 |
|---|---|---|---|---|---|
| 单机 bus89 | 关 | 49.84 Hz | 0.943 pu | 0 | 稳定，无失负荷 |
| 单机 bus89 | 开 | 49.84 Hz | 0.943 pu | 跳1条后 | 潮流不收敛(局部解列) |
| 同源3机(89,80,10) | 关 | **46.09 Hz** | 0.943 pu | 0 | 频率严重跌落 |
| 同源3机(89,80,10) | 开 | 49.82 Hz | 0.943 pu | 跳1条后 | 潮流不收敛(解列) |

**关键机理发现：**

1. **单机 vs 多机共因差异巨大**——单台 607 MW 机组跳闸，系统一次调频/备用可将频率维持在 49.84 Hz；但**同源 3 台大机组共因故障**（市政水网同时断供多厂），机组顺序跳闸（1286s、1560s）使频率跌至 **46.09 Hz**，远低于 UFLS 甚至崩溃阈值。这凸显"共因故障"是本研究最危险的时序模式。

2. **两条级联路径**——冷却水故障可经两条路径危及电网：
   - **频率路径**：大量有功缺额 → 频率跌落 →（多机时）触发 UFLS / 欠频。
   - **潮流路径**：大机组跳闸后潮流向邻近通道转移 → 线路过载 → 过载跳线 → 潮流不收敛（系统解列）。base 案例中 bus89 跳机即触发过载路径。

3. **时序仍是核心变量**——机组跳机时刻由 P1 缓冲时间决定（断水速率、水箱/水池容量），多机跳机的**先后间隔**直接决定频率跌落的叠加深度（3 机在 ~4.5 min 内相继跳闸产生最深跌落）。

## 局限与后续（P4/增强）
- **QSS 近似**：本层用准稳态潮流刻画每个时步的网络稳态，不含机电暂态摇摆细节（RoCoF、暂态稳定）。母线电压变化偏小（slack + 无功未细化），电压路径需后续加无功/AVR 与动态负荷细化。
- **过载判据**为逐条跳最严重线路 + 收敛性判解列，属筛查级；精确保护动作时序可进一步细化。
- **精确 RMS 增强**：可将本框架的机组降额/跳机事件序列导出为 ANDES/PSS-E 的扰动脚本，做机电暂态验证（本环境 ANDES 仅含静态 case118，动态参数需按 `docs/parameter_fitting.md` 补齐）。
- **P4 场景扫描**：按 `scenarios/scenario_matrix.csv`，扫描多机故障间隔 Δt、断水速率、备用比例、过载阈值，绘制级联风险图谱。
