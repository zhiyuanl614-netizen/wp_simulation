## 0. 子模型总览

本研究采用**四层耦合**：W（水源侧水力学）→ A（凝汽器—低压缸热力）→ B（机电）→ C（电网）。
其中子模型 W 是本研究的核心新增，详见独立文档 **`water_side_model.md`**。故障源为**市政水网故障 → 高位补水箱失去补水**。

## 1. 凝汽器—低压缸热力子模型（子模型 A）

### 状态与输入
- 输入（**来自子模型 W**，不再是外部直接给定）：循环水质量流量 `m_cw(t)`、进水温度 `T_cw,in(t) = T_pool(t)`、泵跳闸事件
- 输出：凝汽器压力（背压）`p_b(t)`；并向 W 反馈凝汽器出口热水温度 `T_return(t)`（弱耦合）
- 聚焦范围：仅到**凝汽器—低压缸背压—功率**环节，不含锅炉/给水/高中压缸慢动态

### 控制方程（ε-NTU 简化法）
```
Q_cond      = m_steam * (h_in - h_out)          # 需冷凝的蒸汽热负荷
C_cw        = m_cw * c_p,water                  # 冷却水热容流率
NTU         = U * A / C_cw                       # 传热单元数
epsilon     = 1 - exp(-NTU)                      # 单相凝汽器有效度
T_cw,out    = T_cw,in + Q_cond / C_cw            # 冷却水出口温度
T_sat       = T_cw,in + Q_cond / (epsilon*C_cw)  # 饱和(冷凝)温度近似
p_b         = P_sat(T_sat)                        # 由饱和温度反查饱和压力
```
> 说明：`U*A` 换热能力随流量下降而降低（可用 `U ∝ m_cw^0.8` 近似）；流量骤降 → epsilon 下降 → T_sat 上升 → 背压 p_b 升高。

### 关键参数（需搜集/假设）
| 参数 | 符号 | 典型量级 |
|---|---|---|
| 设计循环水量 | m_cw0 | 视机组容量 |
| 换热面积 | A | m² |
| 传热系数 | U | W/(m²·K) |
| 设计背压 | p_b0 | 4–6 kPa |
| 高背压保护定值 | p_b,trip | 设计值的 ~2–3 倍 |

## 2. 汽轮机功率降额模型（A→B 接口）

背压升高导致低压缸做功能力下降，机械功率降额：
```
k_p(t)  = f(p_b(t))          # 背压—功率修正系数, k_p ≤ 1
P_m,avail(t) = P_m0 * k_p(t) # 可用机械功率上限
```
- `f(·)` 由汽轮机背压—功率修正曲线（微增出力率）给出，初期可用线性/分段近似。
- 当 `p_b(t) ≥ p_b,trip` 且持续 `≥ τ_delay` → 触发高背压保护 → 机组跳闸（P_m → 0）。

## 3. 汽轮机—调速器—发电机机电子模型（子模型 B）

### 发电机转子运动（摇摆方程，每台机）
```
dδ/dt   = ω_s * (ω - 1)
dω/dt   = (P_m - P_e - D*(ω-1)) / (2H)
```
### 调速器（一次调频，TGOV1 型示例）
```
P_m = (1/R) * (ω_ref - ω) 经过 (1+sT1)/(1+sT2)/(1+sT3) 环节
      再乘以背压降额 k_p(t)
```
### 励磁系统
- 采用 IEEE 标准励磁模型（如 ST1A / AC4A），维持机端电压。

### 机组保护逻辑
| 保护 | 判据 | 动作 |
|---|---|---|
| 高背压/低真空 | p_b ≥ p_b,trip，延时 τ | 跳机 |
| 过速 | ω ≥ ω_max | 跳机 |
| 低频/失步 | 参与系统级判据 | 跳机 |

## 4. 电网暂态稳定子模型（子模型 C）

### 网络代数方程
```
I = Y_bus * V            # 复功率注入与母线电压
P_e,i = Re(V_i * conj(I_i))
```
### 负荷模型
- ZIP 静态模型起步，关键母线可加感应电动机动态模型。

### 系统级保护 / 级联判据
| 机制 | 判据 | 动作 |
|---|---|---|
| UFLS 低频减载 | f < f_th（分级） | 切除对应比例负荷 |
| 线路过载 | I_line > I_max，延时 | 线路跳闸 |
| 母线低压 | V < V_th，延时 | 相关元件跳闸 |

### 频率计算
- 采用系统等值惯性中心（COI）频率或母线局部频率。

## 5. 时间尺度与求解设置

| 子模型 | 主导时间常数 | 建议步长 |
|---|---|---|
| A 热力 | 数秒~数十秒 | 0.1–1 s（慢） |
| B 机电 | 毫秒~秒 | 1–10 ms（快） |
| C 电网 | 毫秒~分钟 | 1–10 ms（快）+ 事件驱动 |

**耦合方案：** 外层慢循环（热力，宏观步 ΔT）内嵌快循环（机电/电网，微观步 Δt）；每个宏观步更新 k_p(t) 并注入快循环。详见研究方案第 4.3 节求解策略。
