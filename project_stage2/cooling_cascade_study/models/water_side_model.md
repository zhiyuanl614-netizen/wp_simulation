# 水源侧水力学子模型规范（子模型 W）

**故障源：** 市政供水管网故障 → 高位补水箱失去补水
**配套文档：** `../docs/research_plan.md` 第 4 节、`model_specification.md`
**建模聚焦：** 循环冷却水系统的**水量/水位/流量动态**，为凝汽器子模型提供 `m_cw(t)` 与 `T_cw(t)`。

---

## 1. 系统拓扑与水流路径

```
        市政供水管网
             │  Q_make(t)   ← 故障扰动源（正常≈损失补水量；故障时→0）
             ▼
      ┌──────────────┐
      │  高位补水箱   │  临界设备：容积 V_tank，水位 H_tank
      │ (make-up tank)│
      └──────┬───────┘
             │  Q_gravity（重力/自流补水，随 H_tank 变化）
             ▼
      ┌──────────────┐        Q_evap(蒸发) + Q_blow(排污) + Q_drift(风吹)
      │   集水池      │ ──────────────────────────────────► 损失
      │(cooling basin)│  容积 V_pool，水位 H_pool
      └──────┬───────┘◄─────────────┐
             │  m_cw（循环水泵抽水）   │ 冷却后回水
             ▼                        │
      ┌──────────────┐         ┌─────┴──────┐
      │  循环水泵     │────────►│   凝汽器    │──热水──►┌──────────┐
      │(circ. pump)  │  m_cw   │ (condenser) │        │ 冷却塔    │
      └──────────────┘         └─────────────┘        │(cooling   │
                                                       │  tower)   │
                                                        └────┬─────┘
                                                             │ 冷却后回集水池
                                                             ▼
                                                        （回到集水池）
```

**闭式循环 + 开式补水：** 循环水在"集水池→泵→凝汽器→冷却塔→集水池"内闭式循环；蒸发/排污/风吹造成的净损失由高位补水箱经市政管网补充（开式）。**市政故障切断了这条补充路径。**

## 2b. 建模精细化（v2，依据研究者确认的物理）

四个关键环节已按物理确认细化（对应用户提出的四个问题）：

| # | 环节 | 物理依据 | 模型实现 |
|---|---|---|---|
| 1 | 市政→补水箱 | **市政压力直供 + 液位控制阀**。速率 = Cv·开度·√(市政压头−箱内水位)；水位越接近设定值阀开度越小（P 控制闭环）。**市政故障 = 压头→0 → 补水归零。** | `make_flow()`，参数 `H_muni_head, Cv_make, Kp_tank` |
| 2 | 补水箱→集水池 | **重力自流 + 液位闭环调节阀**。阀开度由集水池水位偏差决定（池位低于设定才开阀）→ **补水量自动"取决于集水池净损失"**；补水箱放空则无水可补。 | `gravity_flow()`，参数 `Cv_gravity, dz, Kp_pool` |
| 3 | 循环水泵→凝汽器 | 正常按额定循环水量满流量运行（`m_cw ≈ Q_cond/(c_p·ΔT)`，ΔT≈8–10 K）；**故障时取决于吸入淹没深度/NPSH**：集水池水位低→NPSH_a 不足→汽蚀致流量降额，跌破最小淹没深度→跳泵。 | `pump_flow()` + `npsh_available()`，参数 `H_submerge_min, submerge_band, NPSH_r, h_suction_fric` |
| 4 | 蒸发/排污/风吹损失 | **随热负荷（出力）变化，非恒定**。蒸发 ∝ 凝汽器热负荷；排污 ∝ 蒸发（浓缩倍率）；风吹 ∝ 循环流量（近恒定）。 | `loss_flow(Q_cond, m_cw)`，参数 `h_fg, blowdown_ratio, drift_frac` |

> **由此产生的重要物理反馈：** 因损失随热负荷变化，当机组因背压升高而降额时，热负荷下降 → 蒸发/排污减少 → 集水池排水变慢 → **缓冲时间延长、跳机推迟**。这是一个温和的**自保护负反馈**，使中等规模共因故障比恒定损失假设下更缓和。稳态初值由 `equilibrate_water()` 积分得到（比例控制存在液位下垂，故平衡水位略低于设定值）。

## 3. 控制方程

### 3.1 高位补水箱水量平衡
```
A_tank * dH_tank/dt = Q_make(t) - Q_gravity(H_tank, H_pool)
```
- `Q_make(t)`：市政补水流量（**故障扰动**，正常 = 系统净损失；故障时按场景降为 0 或按速率衰减）。
- `Q_gravity`：由补水箱向集水池的自流/重力补水，随箱内水位 H_tank 与两者高差变化：
  ```
  Q_gravity = C_v * sqrt( max(0, H_tank + Δz - H_pool) )   # 阀门/管道特性
  ```
  当 `H_tank` 降至最低（放空）→ `Q_gravity → 0`。

### 3.2 集水池水量平衡
```
A_pool * dH_pool/dt = Q_gravity + Q_return - m_cw/ρ - Q_loss
Q_loss = Q_evap + Q_blow + Q_drift        # 循环损失（正常由补水抵消）
Q_return ≈ m_cw/ρ                          # 闭式循环回水（忽略输送损失时近似等于抽水）
```
> 稳态下 `Q_gravity ≈ Q_loss`，水位恒定。市政故障使 `Q_gravity→0`，则 `dH_pool/dt = -Q_loss/A_pool < 0`，水位缓慢下降。

### 3.3 循环水泵特性与流量
```
H_pump = f_pump(m_cw)                      # 泵扬程—流量特性曲线
NPSH_a = (p_atm - p_vap)/(ρ g) + H_pool - h_loss_suction   # 可用汽蚀余量
```
- **汽蚀/低水位判据：** 当 `H_pool < H_pool,min`（吸入淹没深度不足）或 `NPSH_a < NPSH_r`（泵所需汽蚀余量）→ 泵发生汽蚀，流量急剧下降；持续或严重时**循环水泵保护跳泵** → `m_cw → 0`。
- 泵未跳前，流量随水位下降/吸入条件恶化而缓慢下降。

### 3.4 集水池热平衡（供 T_cw,in）
```
ρ V_pool c_p * dT_pool/dt = m_cw c_p (T_return - T_pool) - Q_tower_reject + Q_make_thermal
```
- `T_return`：凝汽器出口热水温度（来自子模型 A 的弱耦合反馈）。
- `Q_tower_reject`：冷却塔散热（随环境湿球温度、塔特性变化）。
- 水量减少会降低系统热惯性，使水温波动加剧。

|---|---|
| `T_return(t)` | 凝汽器出口热水温度 → 影响集水池热平衡 |

## 5. 故障时序刻画（本研究关注的"不同时序"）

市政水网故障可产生**不同发展速率**的水位—流量演化，对应不同的背压上升时序：

1. **补水中断速率：** Q_make 阶跃降为 0（突发爆管）vs. 按速率衰减（逐步减压）。
2. **裕度决定的时延：** 补水箱容积 V_tank + 集水池容积 V_pool + 正常损失率 Q_loss 共同决定"从断水到泵跳闸"的**可用缓冲时间** t_buffer ≈ (可用蓄水量) / Q_loss。这是本研究的关键时序量——它决定了留给应急处置的窗口。
3. **泵跳闸方式：** 低水位保护跳泵（阶跃）vs. 汽蚀致流量渐降（缓变）。
4. **多机耦合：** 同一水源/管网供多台机组时，故障为**共因**，多机近乎同时进入水量亏空 → 电网侧多机顺序/同时跳机。

## 7. 建模简化与假设（起步版）
- 管路输送延迟先忽略（后续可加纯滞后环节）。
- 冷却塔以准稳态散热特性表征，不细化填料传质动态。
- 回水流量近似等于抽水流量（闭式循环、忽略沿程泄漏）。
- 环境条件（湿球温度）先取定值，后续可作为额外扰动维度。
