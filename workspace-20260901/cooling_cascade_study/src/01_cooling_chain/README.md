# P1 — 故障机理链

**阶段目标：** 打通"市政配水节点压头失效(<28m) → 水源侧水位下降 → 循环水泵流量下降/汽蚀跳泵 → 凝汽器背压上升 → 高背压保护跳机 → 机组少发功率"的**完整机理链条**，并产出早期预警指标（跳机时刻=SAET）。影响以**少发功率**衡量，不含系统频率（与 ICS/P6、直流潮流口径一致）。

## 文件

| 文件 | 说明 |
|---|---|
| `params.py` | 参数模块。无现场数据 → 按标准 + 机组额定/实际出力（读 `ieee118_dc/gen.csv`）拟合；含水蒸气饱和线 Antoine 公式 |
| `submodels.py` | 物理层子模型：W 水源侧水力学 / A 凝汽器‑低压缸（ICS、P6 共用）|
| `simulate.py` | 仿真驱动。显式积分打通全链条，事件触发跳泵/跳机；输出跳机时刻(SAET)与少发功率 |
| `plot_results.py` | 结果可视化，输出 6 联图（水位/流量/背压/降额/出力/少发功率）|
| `../results/*.csv` `../results/*.png` | 仿真输出 |

## 运行

```bash
cd src/01_cooling_chain
python simulate.py --t_fault 60 --ramp 0   --t_end 2400   # S01 市政断水阶跃
python simulate.py --t_fault 60 --ramp 600 --t_end 3000   # S02 市政供水渐降(600s)
python plot_results.py                                     # 绘制 results/ 下所有结果
```

参数：`--t_fault` 故障时刻(s)，`--ramp` 市政补水衰减时间(s，0=阶跃)，`--bus` 选取 IEEE118 机组母线（默认 89，最大机组），`--dt` 步长。

## 模型链条与关键机理

```
市政配水节点压头 < 28m (补水中断)
  └─[W]→ 补水箱快速放空(~1min) → 集水池缓慢下降(损失得不到补充)
       └─ 集水池跌破最低淹没深度 → 循环水泵流量降额→汽蚀→跳泵(m_cw→0)
            └─[A]→ 换热能力骤降 → 凝汽器背压飙升(ε-NTU)
                 └─ 背压≥跳机定值+延时 → 机组跳机
                      └─ 机组少发功率 lost = Pg - Pg·k_p (跳机后=Pg)
```
> 少发功率如何被其余机组备用补偿、有无预警的差异，见 `src/02_ics/`（有无预警对比）与 `src/03_proactive_control/`（PA/SP/DP 主动控制）。

**关键时序量：缓冲时间 t_buffer**（断水→跳机）由"补水箱+集水池可用蓄水量 / 循环损失率"决定，是留给应急处置的窗口。

## P1 结果（机理验证，bus89: Pg=607/Pmax=707 MW）

| 场景 | 市政故障形式 | 机组跳机时刻 | 缓冲时间(=SAET) |
|---|---|---|---|
| S01 | 阶跃断水 (ramp=0) | ~5600 s | ~92 min |
| S02 | 渐降 (ramp=600 s) | 更晚 | 更长 |

> 缓冲时间由规范校准后的集水池容积(≈5100 m³, DL/T 5339 停留 4.1 min)与总损失率(≈2.2%, GB/T 50102)决定，约 1.5 h，为电网侧预警处置提供充裕窗口。

> 注：机组跳机时刻即静态可用逃逸时间 SAET（早期预警窗口）；各机组 SAET/ASW 由 `src/03_proactive_control/warning_indicators.py` 计算。影响以少发功率/损失电量衡量（见 `src/02_ics/`、`src/03_proactive_control/`），P1 不含系统频率计算。

**观察：**
1. **链条贯通且时序合理**——市政断水(分钟级)→水位下降→跳泵→背压上升(秒级)→机组跳机，多时间尺度衔接正常。
2. **故障发展速率影响缓冲时间**——市政供水渐降使缓冲窗口(SAET)延长，为电网侧主动处置争取更多时间。

## 说明与定位
- P1 是**故障机理链模块**，其水力-热力子模型（`submodels.py`）为 ICS 与 P6 共用；主要产出为机组跳机时刻(SAET)与预警指标。
- 影响以少发功率/损失电量衡量（见 `src/02_ics/`、`src/03_proactive_control/`）；P1 不含系统频率/直流潮流计算，仅刻画从故障源到机组少发功率的机理链。
- 参数为标准/典型值拟合，绝对量值供参考，**相对趋势与因果时序**是重点。
