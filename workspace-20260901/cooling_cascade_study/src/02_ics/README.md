# ICS —— 工业控制系统 / 信息系统层

**定位：** 在 P0–P5 冷却水—电网耦合项目之上，加入三域独立的**三级工业控制系统（ICS）**，把"早期预警"从理想化假设（手填 `t_detect`）升级为**由信息系统内生产生**的可解释量——市政供水 ICS 检出断供即刻（零时延、可靠）跨域通知电力系统 ICS。

> 物理层复用已验证的解析水力-热力模型（`src/01_cooling_chain/submodels.py`），ICS 作为"信息壳"包在其上。数学模型见 `../docs/mathematical_modeling.md` §6。

## 系统架构（三域独立三级 ICS）

**分层逻辑（依据研究者确认）：市政供水侧、冷却水系统侧、电力系统侧各设独立的三级 ICS。**

- **市政供水域**：独立运行，自有三级 ICS（PLC/SCADA/调度中心）+ 供水管网。
- **电厂侧**（冷却水系统 + 电力系统）：两侧各有三级 ICS，且同属电厂、**厂内双向交互协同**。
- **早期预警链路**：市政供水 ICS 与电力系统 ICS **相互独立**——正因如此，市政 ICS 检出自身断供后，须将预警**跨域传输**给电力系统 ICS，触发电网主动处置。
- **物理耦合**：市政管网 →（市政补水）→ 冷却水系统 →（凝汽器背压→功率降额）→ 电力系统。

```
市政供水 ICS(三级) ──[早期预警,独立跨域]──▶ 电力系统 ICS(三级)
   │(采集/控制)                                  ▲(厂内交互)
市政供水管网 ──[市政补水]──▶ 冷却水 ICS(三级) ◀─┘
                              │(采集/控制)
                     补水箱→集水池→循环水泵→凝汽器 ──[背压→功率降额]──▶ 发电机/电网
```

> 完整架构（三域三级 ICS + 跨域预警链路）已并入论文总体框架图 `../../figures/Fig1_CPS_framework.svg`（原独立 ICS 架构图已合并，不再单列）。

## 检测策略（简化后）

**依据研究者确认，简化如下：**
- **检测只用【市政供水压力】**（源头信号）。补水箱、集水池、凝汽器背压均属**电力系统内部子系统**，彼此存在交互，不作为独立预警监测点。
- **不考虑检测延时/通信丢包/漏报**：市政压头一旦跌破阈值即刻可靠预警（零时延）。
- **只区分两种情形**：有早期预警（WARN） vs 无早期预警（NOWARN，被动）。

| 情形 | 检测量 & 判据 | 检出=预警送达 | 电网响应 |
|---|---|---|---|
| **WARN** | `p_muni` < 28 m（最小供水阈值）| 故障后即刻 | 主动降负荷 + 预置备用/切负荷 |
| **NOWARN** | 不检测 | 无（跳机才知情）| 被动 |

## 结果（单机 bus89）—— 影响以少发功率/损失电量衡量（对齐文献）

| 情形 | 检出/预警 t | 跳机 t | 少发功率峰值 | 损失电量 |
|---|---|---|---|---|
| **WARN 有预警** | 60 s（即刻）| 无（避免跳机）| **0 MW** | **0 MWh** |
| **NOWARN 无预警** | — | ~1768 s | **485.6 MW** | **48.8 MWh** |

**关键结论：**
1. **市政压力是理想的源头预警信号**——市政断供即刻（零时延）在源头检出，无需依赖电力系统内部子系统（补水箱/集水池/背压）的耦合状态。
2. **预警显著降低电力系统影响**——WARN 经预警触发速率受限 runback + 备用预起机，机组不跳、少发功率与损失电量均为 0；NOWARN 被动等跳机，造成 485.6 MW 少发功率峰值、损失 48.8 MWh 电量。
3. **全过程可审计**——SQLite 库（`ics_sim.db`）归档传感器/执行器/告警/调度/预警/快照，可回放与统计。

> 说明：影响以少发功率(MW)与损失电量(MWh)衡量（与参照文献一致）。同源多机共因故障下的 PA/SP/DP 三策略对比见 `src/03_proactive_control/`。

## 与主项目的关系
- **不改物理层**，仅新增信息层；ICS 决定的预警时刻是电网侧主动处置（`ics_simulation.py` 的 runback、`src/03_proactive_control/` 的 LP）的触发来源。
- 按本研究简化，**预警按可靠处理**：不考虑检测延时/通信丢包/漏报，市政压头跌破阈值即刻可靠预警。
