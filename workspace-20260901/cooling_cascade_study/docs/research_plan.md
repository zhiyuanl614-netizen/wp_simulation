# 电厂冷却水故障级联影响动态仿真 —— 初步研究方案

**版本：** v0.3  **日期：** 2026-07-06

## 0. 已确定的研究范围（关键决策）

经与研究者确认，本研究范围锁定如下，后续建模与仿真据此展开：

| 决策项 | 选定 | 影响 |
|---|---|---|
| **机组类型** | 常规**燃煤汽轮机组**（再热凝汽式） | 采用多级再热汽机模型（IEEEG1）；**聚焦凝汽器—低压缸环节，暂不纳入锅炉慢动态** |
| **电网载体** | **固定 IEEE 118**（复用 `ieee118_dc/`） | 无需另建电网；重点补齐 118 系统的发电机动态参数 |
| **研究重点** | **机理揭示**（少量场景深挖） | 场景矩阵精简为若干代表性算例，深入刻画时序因果链 |
| **仿真精度** | **机电暂态 RMS**（相量法） | 采用 RMS 动态仿真（ANDES 等），不做 EMT；步长 ms 级，可覆盖分钟级热力/水力过程 |
| **验证数据** | **无现场数据**，仅 IEEE 118 | 动态参数依据**国家/国际标准**、按机组额定出力与实际出力**拟合赋值**；验证以解析近似 + 文献典型案例 + 软件对标为主 |
| **冷却水故障源** | **市政水网故障**（细化水源侧水力学） | 新增"水源—补水—循环水"水力子模型；临界设备为**高位补水箱** |
| **建模聚焦** | **凝汽器—低压缸** | 汽轮机侧只到低压缸背压—功率环节，不细化锅炉/给水/高中压缸慢过程 |

> 技术路线聚焦为：**市政水网故障 → 水源侧水力学（补水箱/集水池/循环水）→ 凝汽器—低压缸背压机理 → IEEE 118 上的 RMS 机电暂态 → 机理深挖式场景设计**。

## 1. 研究背景与意义

火电机组的冷却水系统是维持汽轮机低压缸背压、保证热力循环效率与机组安全的关键辅助系统。本研究聚焦一类特定但现实的故障：**市政供水管网故障导致电厂高位补水箱无法补水**，进而引发循环冷却水系统水量亏空的连锁反应。完整链条如下：

```
市政水网故障（补水中断）
   → 高位补水箱水位下降 → 无法向集水池补水
      → 集水池水位下降（蒸发/排污/风吹损失得不到补充）
         → 循环水泵吸入条件恶化（有效吸上真空/流量下降，甚至汽蚀/跳泵）
            → 进入凝汽器的冷却水流量下降、换热能力降低
               → 凝汽器真空度恶化、汽轮机低压缸背压升高、出力降额
                  → 高背压/低真空保护动作 → 机组甩负荷或跳机
                     → 电网瞬时有功缺额 → 频率跌落、潮流转移、电压波动
                        → 若超出保护/稳定裕度 → 其他机组/线路保护动作 → 级联扩散
```

传统电力系统安全分析多以"N-1 电气故障"为对象，**极少将电厂供水侧（市政水网）故障作为扰动源**，也较少刻画从"水力学扰动"经"热力—机电"到"电网级联"的完整时序链条。本研究旨在填补该空白，为发电侧供水安全预警与电网韧性评估提供仿真手段与量化依据。

### 研究价值
- **机理层面：** 建立"市政水网—补水箱—集水池—循环水—凝汽器—低压缸—发电机—电网"全链条耦合动态模型，揭示故障传播机理与关键时序节点。
- **工程层面：** 量化不同故障时序（补水中断速率、水箱/水池容量裕度、单机 vs. 多机、有无应急补水/降负荷）对电网频率/电压/潮流的冲击。
- **决策层面：** 为供水应急预案、机组降负荷策略、电网切机切负荷方案提供仿真支撑。

## 2. 研究目标

### 2.1 总体目标
构建冷却水故障驱动的**多时间尺度耦合动态仿真框架**，实现从电厂辅助系统扰动到电网级联响应的全过程刻画，并在不同故障时序场景下评估电网稳定性与级联风险。

### 2.2 具体目标
1. **建模目标：** 建立冷却水系统—凝汽器热力子模型、汽轮机—调速器—发电机机电子模型、电网潮流/暂态稳定子模型，并明确三者的耦合接口与时间尺度衔接。
2. **仿真目标：** 设计并实现不同时序（故障发展速率、发生时刻、多机同时/顺序故障、保护/备用动作时序）下的动态仿真算例。
3. **分析目标：** 以**少发功率(MW)与损失电量(MWh)**（对齐参照文献）衡量水源中断对电力系统的影响，对比有无早期预警、被动/静态主动/动态主动(PA/SP/DP)三策略。
4. **验证目标：** 通过与解析近似、参照文献（孙宏斌团队 Nat.Commun.2024）方法对齐，验证模型与结论可信度。

## 3. 研究对象与系统边界

| 层级 | 对象 | 关注量 | 主导时间尺度 |
|---|---|---|---|
| **水源/水力** | 市政管网、高位补水箱、集水池、循环水泵、冷却塔 | 补水流量 Q_make、水箱/水池水位 H、循环水流量 m_cw、水温 T_cw | 数十秒 ~ 数十分钟 |
| 热力本体 | 凝汽器真空、汽轮机低压缸 | 背压 p_b、排汽焓、机械功率 P_m | 秒 ~ 数十秒 |
| 机电本体 | 调速器、汽轮机、发电机、励磁 | 转速/频率、机械/电磁功率、机端电压 | 毫秒 ~ 秒 |
| 电网系统 | 输电网、负荷、保护 | 系统频率、母线电压、支路潮流 | 毫秒 ~ 分钟 |

**系统边界（更新）：**
- **上边界：市政水网故障作为外部扰动输入**——以补水流量 Q_make(t) 的时间函数表征（如 t=0 突降为 0，或按一定速率衰减）。水源侧水力学**纳入建模**：市政管网→高位补水箱→集水池→循环水泵→凝汽器→冷却塔→回集水池，形成闭式循环 + 开式补水。
- 下边界：电网级联以保护动作（机组跳闸、线路过载/低频/低压跳闸、UFLS 低频减载）为终点，不含配电网细节。
- 建模聚焦：汽轮机侧只到**凝汽器—低压缸**背压—功率环节，**不纳入锅炉/给水/高中压缸慢动态**。
- 测试电网：采用 **IEEE 118 节点系统**（复用 `ieee118_dc/` 拓扑与参数）作为电网载体；将若干大机组指定为"受冷却水故障影响机组"。机理验证阶段先在单机—无穷大母线（SMIB）上打通全链条。

## 4. 技术路线（多时间尺度耦合思路）

本研究的核心难点在于**时间尺度跨度大**（热力过程分钟级、机电暂态毫秒级）。采用"分层建模 + 接口耦合 + 分段/联合求解"的技术路线。

### 4.1 四层耦合模型

**(W) 水源侧水力学子模型（最慢动态，Δt ~ 1–10 s）——本研究新增核心**
- 故障源：市政管网故障 → 补水流量 `Q_make(t)`（外部输入，如阶跃降为 0）。
- 系统结构（详见 `docs/water_side_model.md`）：
  ```
  市政管网 ──Q_make──▶ 高位补水箱 ──Q_gravity──▶ 集水池 ◀──回水──┐
                       (临界设备)               │              │
                                          循环水泵 m_cw     冷却塔
                                                │              ▲
                                                ▼              │
                                             凝汽器 ───热水────┘
  ```
- 核心：高位补水箱、集水池的**水量平衡（质量守恒）**微分方程 + 循环水泵特性（扬程—流量、NPSH 汽蚀判据）。
- 输出：循环水流量 `m_cw(t)`、集水池水温 `T_cw(t)`，以及"泵是否因低水位/汽蚀跳闸"的事件。

**(A) 凝汽器—低压缸热力子模型（慢动态，Δt ~ 0.1–1 s）**
- 输入：来自子模型 W 的循环水流量 `m_cw(t)`、进水温度 `T_cw(t)`。
- 核心：凝汽器换热方程（ε-NTU 或对数平均温差法）→ 冷凝压力/真空度 → 汽轮机低压缸背压 `p_b(t)`。
- 输出：背压 p_b(t) → 传递给汽轮机模型，修正可用机械功率上限 / 机械功率 P_m。

**(B) 机组机电子模型**
- 机械功率受背压降额（k_p）与主动降负荷指令共同决定；高背压/低真空保护延时跳机（本研究关键触发环节）。
- 受影响机组因水源中断而少发的功率 = 影响量化的源头。

**(C) 电网子模型（直流潮流，与文献一致）**
- 少发功率由其余机组两级备用（旋转备用 + 慢起机备用）补偿，未覆盖部分即电力系统承受的**少发功率(MW)**，积分得**损失电量(MWh)**。
- 主动控制用线性规划求解（目标 min 损失电量，约束含功率平衡/容量/爬坡/**直流潮流 PTDF**），对比被动/静态主动/动态主动(PA/SP/DP)。

### 4.2 耦合接口

| 接口 | 传递变量 | 方向 |
|---|---|---|
| W → A | 循环水流量 m_cw(t)、进水温度 T_cw(t)、泵跳闸事件 | 水力→热力 |
| A → B | 背压 p_b(t) → 机械功率降额系数 k_p(t) | 热力→机电 |
| B → C | 受影响机组少发功率 lost(t) | 机电→电网 |
| C → B | 主动降负荷指令（预警后）、备用补偿 | 电网→机电 |
| B → A | （弱耦合）机组负荷率影响排汽量 → 凝汽器热负荷 Q_cond | 机电→热力 |
| ICS | 市政供水 ICS 检出压头失效 → 跨域预警 → 电力 ICS 触发主动处置 | 信息层 |
| A → W | （弱耦合）凝汽器热负荷影响回水温度 → 集水池热平衡 | 热力→水力 |

### 4.3 求解策略（三选一，逐步推进）
1. **准稳态解耦（起步、快速出结果）：** 热力子模型独立求解得到 p_b(t) 与机械功率降额曲线；将其作为时变输入注入电网暂态稳定仿真。适合初步敏感性分析。
2. **交替迭代协同（中期）：** 在每个宏观时间步内，热力与机电模型交替求解、交换接口变量，收敛后推进。
3. **联合积分（进阶）：** 统一 DAE 系统，采用变步长隐式积分（如 Backward Euler / 梯形法）同时求解，精度最高、实现最复杂。

**建议：** 先用策略 1 打通全链条与指标体系，再视需要升级到策略 2/3。

## 5. 仿真场景与时序设计

围绕"不同时序"这一核心诉求，从**四个维度**组织场景（详见 `docs/scenario_matrix.csv`）：

1. **故障发展速率：** 突变（泵瞬时停运）/ 渐变（结垢、缓慢堵塞，分钟级）。
2. **故障发生范围：** 单机 / 同一电厂多机 / 跨厂多机（共因，如取水口高温）。
3. **故障发生时序：** 同时发生 / 顺序发生（间隔 Δt）—— 重点考察级联叠加效应。
4. **应对措施时序：** 无动作 / 备用泵切换（切换延时 τ）/ 机组主动降负荷（RUNBACK）/ 电网 UFLS。

对每个场景，扫描关键时序参数（故障速率、发生间隔、保护延时、备用切换时间），构成参数敏感性分析矩阵。

## 7. 研究方法与工具

### 7.1 仿真平台（候选，按推荐度）
- **Python 生态（推荐起步）：** `ANDES`（开源电力系统动态仿真，支持自定义模型与 DAE 求解）或 `pandapower + 自研动态外壳`；热力子模型用 `scipy.integrate` 自建。优点：开源、可深度定制耦合接口、便于批量场景扫描。
- **专业软件（对标/验证）：** DIgSILENT PowerFactory、PSS/E、PSCAD/EMTDC（电磁暂态）、以及热力侧的 Modelica/Dymola（`ThermoPower` 库）。用于结果交叉验证。
- **联合仿真（进阶）：** Modelica（热力）+ 电力系统仿真器，通过 FMI 接口协同。

### 7.2 数据需求与参数拟合策略

**由于无现场数据，动态参数按"国家/国际标准 + 按额定/实际出力拟合"的方式赋值：**

- **电网动态参数：** IEEE 118 拓扑/潮流已有，但缺发电机 H、Xd′、调速/励磁参数。策略：
  - 按机组**额定容量分档**（如 <100 MW、100–300 MW、300–600 MW、>600 MW），依据 IEEE/IEC 标准与 WECC/CIGRE 典型参数库赋值；
  - 惯性常数 H、调差系数 R 等按 `实际出力 Pg / 额定容量 Pmax` 的比值对典型值做**插值/拟合缩放**（现有 `gen.csv` 已含 Pg、Pmax，可直接用于拟合）；
  - 汽轮机采用 **IEEEG1**（再热汽机）标准模型，励磁采用 IEEE ST1A/AC4A 标准模型。
- **机组热力参数：** 凝汽器设计参数（换热面积、设计循环水量、设计端差、设计背压）按机组容量档位依据行业设计标准（如 GB/T、ASME、HEI 凝汽器标准）取典型值并按额定功率标定。
- **水源侧参数：** 高位补水箱容积与几何、集水池容积、循环水泵扬程—流量特性与 NPSH、冷却塔冷幅/冷却温差、正常补水率（蒸发+排污+风吹损失），依据电厂循环水系统设计规范取典型值。
- **拟合原则：** 以"额定工况自洽"为约束——在额定出力下反推设计背压、设计循环水量等，保证稳态基准点物理一致；故障工况再在此基准上演化。参数与来源统一登记于 `docs/parameter_fitting.md`。

### 7.3 与已有 DC 算例的关系
- 复用 `ieee118_dc/` 的网络拓扑与稳态潮流作为初始运行点。
- 与参照文献一致，主动控制 LP 全程采用**直流潮流(DC-PF/PTDF)**表达支路潮流约束（详见 `mathematical_modeling.md` §5、§7A）。

## 10. 风险与开放问题
- **时间尺度耦合的数值稳定性**：慢/快动态刚性问题，需谨慎选择积分方法与步长。
- **动态参数缺失**：IEEE 118 缺原生动态数据，参数假设会影响结论的绝对量值（相对趋势仍有效）。
- **热力模型简化程度**：凝汽器/汽轮机模型的精度与计算成本权衡。
- **保护建模的真实性**：保护定值与延时对级联结果高度敏感，需尽量贴近实际。
- **验证数据难获取**：真实冷却水故障级联案例稀少，验证以文献典型案例 + 软件对标为主。

## 11. 已确认与待确认事项

### 已确认
