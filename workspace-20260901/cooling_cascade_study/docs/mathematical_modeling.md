# 数学建模文档 —— 冷却水故障级联与早期预警韧性

**文档定位：** 完整、独立地描述本研究全部子模型的**数学函数、控制方程、理论方法与参数**，与实现代码（`src/01_cooling_chain/`、`src/02_ics/`、`src/03_proactive_control/`）逐一对应。符号、常数与代码一致，便于复现与审阅。

**版本：** v1.0　**日期：** 2026-07-06
**代表机组：** IEEE-118 母线 89（额定 P_max=707 MW，实际出力 P_g=607 MW）

## 0. 总体框架与理论基础

系统按**四层 + 信息层**耦合，跨越多个时间尺度：

| 层 | 子模型 | 理论方法 | 主导时间尺度 |
|---|---|---|---|
| W | 水源侧水力学 | 质量守恒 + 孔口/阀门水力学 + 比例控制 + NPSH 汽蚀理论 | 数十秒—数十分钟 |
| A | 凝汽器—低压缸 | 换热器 ε‑NTU 理论 + 水蒸气饱和线(Antoine) + 汽轮机微增出力率 | 秒—数十秒 |
| B | 机组机电 | 背压降额 + 少发功率/损失电量 | 秒 |
| C | 电网 | 直流潮流(PTDF) + 两级备用平衡 + 主动控制LP | 秒—分钟 |
| ICS | 信息系统 | 阈值检测 + 事件触发 + 零时延可靠预警（本研究简化）| 事件驱动 |

**统一时间推进：** 显式欧拉，宏观步长 Δt（P1 取 0.05 s，ICS 取 4 s，P6 LP 取 2–3 min）。每步先解慢过程（水力→热力，代数），再算少发功率与备用补偿，事件（跳泵/跳机）按状态判据触发。

**符号约定：** H 水位(m)，Q/m 体积流量(m³/s)，p 压力，T 温度(°C)，P 功率(MW)，f 频率(Hz)，下标 0 表示额定/初始。

## 1. 子模型 W —— 水源侧水力学

**失效源（建模起点）：** 市政供水管网**配水节点压力水头低于最小供水阈值 H_muni_min = 28 m**，配水节点无法为高位补水箱补水——这是整个级联的起点。同一时刻，市政供水 ICS 检出压头 < 28 m，将预警发送给电力系统 ICS（早期预警）。系统结构为"闭式循环 + 开式补水"：

```
市政管网 ──补水──▶ 高位补水箱 ──自流──▶ 集水池 ◀──回水──┐
                                        │循环水泵         │
                                        ▼                冷却塔
                                     凝汽器 ──热水────────┘
```

### 1.1 市政供水压头与失效判据（建模起点）

市政配水节点供水压头 `H_muni(t)`（对应代码 `muni_head`）：

```
             ⎧ H_muni0                                  , t < t_fault
H_muni(t) =  ⎨ 0                                        , t ≥ t_fault, ramp = 0  (阶跃失压)
             ⎩ H_muni0 · max(0, 1 − (t−t_fault)/ramp)   , t ≥ t_fault, ramp > 0  (渐降)
```

**失效判据（本研究的起点）：** 当配水节点压头低于**最小供水阈值** `H_muni_min` 时，配水节点无法克服高位补水箱的静压与管路阻力，**补水中断**：

```
供水失效  ⟺  H_muni(t) < H_muni_min = 28 m
```

参数：`H_muni0 = 32 m`（正常，须 > 最小阈值方能为高位补水箱供水），`H_muni_min = 28 m`（最小供水阈值），`t_fault` 故障时刻，`ramp` 失压时间常数。**同一时刻市政 ICS 检出压头 < 28 m 并发出早期预警（见 §6.1）。**

`H_muni(t)` 有**两种来源**（见 §1.1a）：**(基线) 参数化轨迹** —— 直接用上式的 `t_fault/ramp`（对应同源单点故障，`src/01_cooling_chain/`、`src/03_proactive_control/`）；**(增强) 真实管网仿真生成** —— 由市政水网基准模型 D-town 仿真得到各电厂配水节点的压头轨迹，各节点跌破 28 m 的时刻天然不同（对应多源错峰故障，`src/00_muni_wdn/`）。

### 1.1a 市政水网边界生成器（真实基准管网, 多源错峰失压）

**角色定位（上游边界生成器，不与下游耦合求解）：** 用真实基准配水管网 **D-town** 的水力仿真，生成各电厂配水节点的压头轨迹 `H_muni_i(t)`；经"最小供水阈值 28 m"判据，得到各电厂供水失效时刻 `t_fault_i`。下游冷却水/电力/主动控制模型完全不变，只把 `t_fault_i`（及等效 `ramp_i`）作为边界参数读入。对应 `src/00_muni_wdn/boundary_generator.py`。

**为何市政水网只作边界、不耦合进下游（缓冲位置不对称，关键论证）：** 参照文献气网**必须**做网络水力仿真，因为缓冲（line pack 管存气）**分布在管网内**，AET/SAET 由管存气算出，网络仿真是缓冲物理的载体。本项目缓冲（可用储水量 ASW）在**电厂内部**（高位补水箱 + 集水池），是**集总**的、不在市政管网里；故市政管网对下游只是一个**压力边界**，不承载任何下游需要的缓冲物理。因此用它**生成** `H_muni_i(t)` 即充分，无需将其耦合进下游求解。

**同源 vs 多源两类案例（对齐文献两级案例）：**
- **同源（对齐文献 Fig.5–6，单气源 GS 累及多厂）：** 单一市政总源/单一配水点失效，同时波及同源多机——用基线参数化轨迹即可（`src/03_proactive_control/`）。
- **多源错峰（对齐文献 Fig.7，多端源省级案例）：** 市政总源（水库）失效后，经**不同 DMA 分区**的水箱缓冲与管网距离，各电厂配水节点在**不同时刻**跌破阈值 → 各机组得到**不同 SAET_i**——由 D-town 仿真真实生成，无需人为指定各失压时刻。这正镜像文献"SAET 随与故障点距离从数分钟到数小时不等"。

**为何用 D-town 而非 C-town（数据真实性）：** 同一 BWN 系列的 C-town 导出版 `[JUNCTIONS]` 需水量全为 0、无城市负荷（校准用拓扑骨架），需**人为补背景负荷**才能让水箱排空——引入人为成分。**D-town 是 C-town 拓扑的带真实需水量改进版**（2013 BWN 长期改进竞赛）：399 节点中 **348 个有真实需水、5 条日变化需水模式**、7 个分区水箱、单水库总源。城市负荷真实，消除了 C-town 版的唯一不真实成分。

**D-town 基准模型：** 单水库 R1（市政总源）+ 11 泵 + 7 水箱（T1–T7，分区缓冲）+ 399 节点 + 443 管段 + 5 阀，分层 DMA 结构，含真实城市需水量。三座电厂取水点分处不同 DMA 供区（J411/J371/J197，正常压头 66/67/74 m）。**故障施加（水源压头下降）：** t=6 h 起水库 R1 压头在 3 h 内线性降至近零 → 配水节点压力逐级失效（比硬切管道更贴合"市政供水压力失效"的物理本意，且保持水力求解良态）。**结果（错峰失压）：** 三电厂配水节点分别在故障后 **+26.0 / +28.0 / +61.0 h** 跌破 28 m（bus10 由 T3 高区水箱强缓冲拖至最久）。

**仿真方法与说明（如实标注）：**
1. **EPANET 2.2 EPS 而非水锤暂态：** 扩展时段准稳态（分钟级），非亚秒级压力波——与本项目关心的失压传导时间尺度（SAET，分钟~小时）一致；水质(水龄)分析关闭，只解水力。
2. **压力驱动需水（PDD）：** 压力不足时供水量按物理削减（`required_pressure=15 m`），而非强行满足。
3. **真实城市需水量：** D-town 自带 348 节点真实需水 + 5 条日变化模式，图中昼夜起伏即真实日变化需水所致（高区水箱夜间重力供水），无需人为补背景负荷。
4. **失效时刻取首次跌破：** 各配水节点随其供区水箱逐级耗尽而先后失效；下游只取各节点**首次**跌破 28 m 的时刻并锁存。

**数据来源（CC BY-NC 4.0，须署名）：** Ostfeld, Avi. *"05 Long Term Improvement" (D-town)* (2016). Battle of the Water Network Models. University of Kentucky Libraries. https://uknowledge.uky.edu/wdst_models/5

### 1.1b 唯一水源停供 → 全网压力崩溃（全网时空分析）

除"3 个电厂取水点错峰"（§1.1a）外，本研究另做一项**全网时空分析**：模拟 D-town **唯一水源（水库 R1）完全停止供水**这一确定事件后，**整个管网全部 399 节点压力的时空演化**——失压如何从水源处开始、随各分区水箱逐级放空而在空间上扩散。对应 `src/00_muni_wdn/network_outage.py`。

**停供施加（阶跃，自 t=0 起）：** 水源 R1 压头自仿真起始时刻（t_fault = 0）即降至近零并保持（唯一水源自始完全停供）：
```
H_R1(t) = ≈0     , t ≥ 0      (自 t=0 起阶跃停供)
```
**为何用"压头→0"而非"硬切出水管"：** 硬切会使 EPANET 稳态解在无水可供的节点算出大量**非物理负压**（可达 −10⁴ m）；"压头→0" + 压力驱动需水(PDD) + `minimum_pressure = 0`（无水时压力钳制为 0）则**物理正确**——水源停供后由 7 个分区水箱储水续供，水箱逐级放空后所在区才真正失压。

**物理正确性（缓冲窗口 + 空间扩散）：** 自 t=0 停供后压力**并不立即崩溃**——全网水箱靠储水继续供水，维持约 12 h（缓冲窗口，与 §7A.1 的 ASW/SAET 缓冲思想一致，只是这里在市政侧）；随水箱见底，失压节点（压头 < 28 m）占比从初始 ~10% 扩大到 ~62%，**全网半数节点在停供后约 12.5 h 失压**，呈自水源向外的空间扩散。

**输出：** `results/network_outage.json`（全网压力统计时间序列 + 4 个快照时刻逐节点压力 + 拓扑坐标）；`results/network_outage.png`（① 全网压力统计随时间 ② 失压节点占比随时间 ③–⑥ 空间快照，节点坐标着色压力，蓝=健康、红=失压）。

### 1.2 市政 → 补水箱 补水流量（孔口 + 比例液位阀）

理论：**孔口/阀门流量公式** `Q = C_v·u·√(Δh)`，阀开度 u 由**比例(P)液位控制**给出（对应 `make_flow`）：

```
若 H_muni(t) < H_muni_min = 28 m  ⟹  Q_make = 0        (失效源: 配水节点无法供水)
否则:
  Δh_make = H_muni(t) − H_tank                          (有效驱动压头)
  u_make  = clip( K_p^tank · (H_tank^set − H_tank), 0, 1 )        (P 控制阀开度)
  u_make  = max(u_make, 0.02)   若 H_tank < H_tank^set            (防全关死)
  Q_make  = C_v^make · u_make · √(max(0, Δh_make))
```

**物理含义：** 正常时市政压头(32 m) > 补水箱水位，补水正常；一旦配水节点压头跌破最小供水阈值(28 m)，补水立即中断——这是级联的**起点**。
参数：`C_v^make=0.30`，`K_p^tank=0.5`，`H_tank^set=4 m`，`H_muni_min=28 m`。

### 1.3 补水箱 → 集水池 自流（重力 + 比例液位阀）

理论：重力自流 `Q = C_v·u·√(有效水头)`，阀开度由**集水池**液位偏差闭环（对应 `gravity_flow`）：

```
Δh_grav  = H_tank + Δz − H_pool                        (含高差 Δz 的驱动水头)
u_grav   = clip( K_p^pool · (H_pool^set − H_pool),  0, 1 )
Q_grav   = C_v^grav · u_grav · √(max(0, Δh_grav)) ,   且 H_tank > H_tank^min 才有流量
```

**物理含义：** 补水量"按需"——集水池低于设定才开阀；补水箱放空(H_tank≤0)则无水可补，故障沿链传播。
参数：`Δz=15 m`，`C_v^grav=0.60`，`K_p^pool=0.8`，`H_pool^set=3 m`。

### 1.4 循环水泵流量（NPSH / 淹没深度判据）

理论：**汽蚀余量(NPSH)**。可用汽蚀余量（对应 `npsh_available`）：

```
NPSH_a = (p_atm − p_vap)/(ρ_w·g) + H_pool − h_fric ,     h_fric = h_fric0·(m_cw/m_cw0)²
```

循环水泵流量按淹没深度分段（对应 `pump_flow`）：

```
            ⎧ 0                                  , 跳泵 或 H_pool ≤ H_sub^min   (汽蚀跳泵)
m_cw     =  ⎨ m_cw0 · (H_pool − H_sub^min)/band  , H_sub^min < H_pool < H_sub^min+band  (汽蚀降额)
            ⎩ m_cw0                              , 否则  (额定满流量)
```

额定循环水量按机组容量标定：`m_cw0 = 0.0295 · P_max`（m³/s）≈ 21 m³/s，对应设计温升 8 K（**GB/T 50102** 循环水温升 8–10 K）。
参数：`H_sub^min=1.2 m`（跳泵淹没线），`band=0.5 m`，`p_atm=101.325 kPa`，`h_fric0=1 m`。

### 1.5 冷却水循环损失（随热负荷变化）

理论：蒸发量 ∝ 冷却塔散走的热量 ∝ 凝汽器热负荷；排污 ∝ 蒸发；风吹 ∝ 循环流量（对应 `loss_flow`）：

```
Q_evap  = Q_cond / (h_fg · ρ_w)              (蒸发, ∝ 热负荷)
Q_blow  = β_bd · Q_evap                      (排污, β_bd = 排污/蒸发)
Q_drift = α_dr · m_cw                         (风吹/飘滴, ∝ 流量)
Q_loss  = Q_evap + Q_blow + Q_drift
```

参数：`h_fg=2400 kJ/kg`（汽化潜热），`β_bd=0.52`（浓缩倍率≈3），`α_dr=5×10⁻⁴`。总损失≈2.2% 循环量（**GB/T 50102**：循环冷却水总损失 2–3%）。
**关键反馈：** 机组降额 → Q_cond 下降 → Q_evap 下降 → 集水池排水变慢 → 缓冲时间延长（"降额自保护"负反馈）。

### 1.6 水箱/集水池 质量守恒（状态微分方程）

理论：**质量(体积)守恒**。两个储水单元的水位动态（对应 `water_derivs`）：

```
高位补水箱:   A_tank · dH_tank/dt = Q_make − Q_grav
集水池:       A_pool · dH_pool/dt = Q_grav + Q_return − m_cw − Q_loss
其中 闭式回水  Q_return ≈ m_cw  ⟹  A_pool · dH_pool/dt = Q_grav − Q_loss
```

边界夹紧：H_tank∈[H_tank^min, H_tank^set]，H_pool≥0。
参数：`A_tank=30 m²`（补水箱 120 m³），`A_pool=1700 m²`（集水池 ≈5100 m³，停留时间 4.1 min，符合 **DL/T 5339** 吸水井 3–5 min）。

### 1.7 集水池水温（准稳态冷却塔）

理论：冷却塔把回水冷却到"湿球 + 冷幅"，流量不足时冷却能力下降（对应 `basin_temp`）：

```
T_tower_out = T_wb + approach
              ⎧ T_return                                            , m_cw = 0 (失去冷却)
T_cw_in   =   ⎨ T_tower_out + (1 − m_cw/m_cw0)·0.5·(T_return − T_tower_out) , 否则
              ⎩
```

参数：`T_wb=15°C`（湿球），`approach=5 K`（冷幅）⟹ 设计进水温 ≈ 20°C。

### 1.8 稳态初值（液位下垂平衡）

比例控制存在**液位下垂**：稳态水位略低于设定值（阀微开恰好补偿损失）。初值由 `equilibrate_water` 将 §1.6 积分至 dH/dt≈0 求得（bus89：H_tank≈3.42 m，H_pool≈2.79 m）。

## 2. 子模型 A —— 凝汽器 / 低压缸

### 2.1 水蒸气饱和线（Antoine 方程）

理论：**Antoine 方程**，双向换算饱和温度↔饱和压力（对应 `psat_from_t` / `tsat_from_p`）：

```
log10(p_sat[mmHg]) = A − B/(C + T)         (T in °C)
p_sat[kPa] = p_sat[mmHg] × 0.1333224
T_sat(p)   = B/(A − log10(p[mmHg])) − C
```

系数（水，1–100°C）：`A=8.07131, B=1730.63, C=233.426`。校验：p_sat(33°C)≈5.0 kPa，T_sat(5 kPa)≈33°C。

### 2.2 凝汽器换热（ε‑NTU 理论）

理论：**换热器有效度‑传热单元数(ε‑NTU)法**，单相冷却介质凝汽器（对应 `condenser`）：

```
C_cw  = m_cw · ρ_w · c_p,w                    (冷却水热容流率, kW/K)
UA    = UA0 · (m_cw/m_cw0)^n                  (总传热系数随流量, n=0.8, Dittus–Boelter 类比)
NTU   = UA / C_cw
ε     = 1 − exp(−NTU)                         (单相凝汽器有效度)
T_ret = T_cw_in + Q_cond / C_cw               (冷却水温升, 能量守恒)
T_sat = T_cw_in + Q_cond / (ε · C_cw)         (蒸汽冷凝温度)
p_b   = p_sat(T_sat)                          (凝汽器背压, 由饱和线)
```

断流保护：m_cw≈0 时换热停止，p_b 置高值（≈3×跳机定值）。
参数标定（`__post_init__`）：由额定工况（p_b0=5 kPa，进水温 20°C，Q_cond0=1.15·P_g·1000 kW）反算 `UA0`，保证额定点自洽。
常数：`ρ_w=1000 kg/m³`，`c_p,w=4.187 kJ/(kg·K)`，`UA_exp n=0.8`。

### 2.3 汽轮机背压—功率降额（微增出力率）

理论：汽轮机**背压微增出力率**线性化（对应 `power_derate`）：

```
Δp_b = max(0, p_b − p_b0)
k_p  = max(0, 1 − γ · Δp_b)                   (机械功率降额系数, ≤1)
```

参数：`p_b0=5 kPa`（设计背压），`γ=0.02 /kPa`（背压每升 1 kPa 出力降 2%）。

### 2.4 高背压保护（带延时跳机）

事件判据：背压超限并持续 τ_delay 即跳机：

```
若 p_b ≥ p_b^trip 持续 ≥ τ_delay  ⟹  机组跳闸 (P_m → 0)
```

参数：`p_b^trip=15 kPa`（≈3×设计），`τ_delay=3 s`。

### 2.5 凝汽器热负荷（弱耦合更新）

```
             ⎧ 1.15 · (P_g · out_frac) · 1000        , 未跳机  (∝ 实际出力)
Q_cond(t) =  ⎨ max(0, Q_cond − Δt·Q_cond0/20)        , 跳机后  (残余排汽 ~20 s 衰减)
             ⎩
```
其中 out_frac 为实际出力比例（含主动降负荷，见 §4.2）。此式把 A 与 W（§1.5 损失）、B（出力）耦合。

## 3. 子模型 B —— 机组机电与影响量化

### 3.1 机组跳机与少发功率

受影响机组的机械功率受背压降额，跳机后为零：
```
P_aff(t) = P_aff0 · out_frac(t)      (out_frac = min(降负荷指令, k_p); 跳机后=0)
少发功率  lost(t) = P_aff0 − P_aff(t)     (受影响机组因水源中断而少发的功率, MW)
```
其中 `out_frac` 含主动降负荷指令（见 §4.2）与背压降额系数 `k_p`（见 §2.3），取更严者。

### 3.2 电力系统承受的功率缺额 / 损失电量（影响指标）

理论：**有功平衡** —— 受影响机组的少发功率由其余机组的两级备用补偿，未覆盖部分即电力系统承受的少发（对应 `ics_simulation` / `proactive_lp`）：

```
pickup(t)   = min( lost(t),  R_spin + R_slow(t) )        (备用实际补偿, 见 §4.1)
deficit(t)  = max(0, lost(t) − pickup(t))                (功率缺额=少发功率, MW)

影响指标(与参照文献一致):
  少发功率峰值   P_def^max = max_t deficit(t)                    (MW)
  损失电量       E_def = ∫ deficit(t) dt                        (MWh)
```

**说明：** 本研究以**少发功率(MW)与损失电量(MWh)**衡量水源中断对电力系统的影响（与参照文献一致），全项目不含系统频率计算——这与采用直流潮流(DC-PF)的建模口径一致（直流潮流忽略电压/无功、只解相角，本就不产生频率维度）。

## 4. 备用体系与主动处置（研究核心机制）

### 4.1 两级备用（旋转备用 + 慢起机备用）

理论：**旋转备用（快，随时可用）+ 慢起机备用（需时间）**，与参照文献一致的两级备用体系。这是"预警价值"的物理载体。

```
旋转备用:      R_spin = r_frac · P_aff0            (快速可用, 立即顶上)

慢起机备用(速率受限):
   R_slow(t) = min( C_slow , rate_slow · elapsed )
   elapsed = ⎧ t − t_warn        , 主动预警(预警时刻起机)
             ⎩ t − t_firsttrip   , 被动(首台跳机后才起机)
```

参数：`r_frac=0.20`（旋转备用占受影响机组出力），`C_slow` 慢起机备用容量，`rate_slow` 起机速率（~15 min 全部到位）。

**核心因果：** 受影响机组容量常 > 旋转备用 ⟹ 仅旋转备用不足以承受跳机。慢起机备用起机需时间，恰可用水力缓冲窗口（SAET）经预警**提前启动** ⟹ **有无早期预警直接决定跳机时刻已就位的备用量**。

### 4.2 主动降负荷（runback，速率受限）

理论：预警后逐步降低机组出力指令，实现"make‑before‑break"平滑转移。**关键约束：卸载速率不得快于备用补充速率**，否则自造缺额（对应 `_step_unit`）：

```
若已预警且未跳机:
   rate_cap = rate_slow / P_aff^total                   (速率上限 = 备用起机速率)
   eff_rate = min( runback_rate_frac , rate_cap )
   cmd_frac ← max( 0 , cmd_frac − eff_rate·Δt )
out_frac = min( cmd_frac , k_p )                         (实际出力取指令与背压降额较严者)
```

副效应：降负荷 → Q_cond 下降（§2.5）→ 背压上升减缓 → 延后甚至避免跳机。

## 5. 子模型 C —— 电网（直流潮流）

**潮流方法：** 与参照文献一致，全流程采用**直流潮流(DC-PF)**；主动控制 LP 中用 **PTDF 灵敏度**表达支路潮流约束。详细的 LP 形式见 §7A.2。

### 5.1 直流潮流（PTDF 线性模型）

理论：**直流潮流**忽略电阻/无功/电压幅值，支路有功潮流对节点净注入线性（对应 `dc_network`）：

Pf_ℓ = Σ_n PTDF[ℓ,n] · Pinj_n          (Pinj = P_gen − P_load, MW)

## 6. 信息系统层（ICS）—— 早期预警

理论：三域独立的三级 ICS（PLC/SCADA/调度中心）。市政供水 ICS 与电力系统 ICS **独立运行**，故需早期预警链路；冷却水侧与电力系统侧 ICS 厂内交互。

### 6.1 检测判据（市政供水压力，源头信号）

**本研究简化：** 只监测市政供水压力，不考虑检测延时/通信丢包/漏报（零时延、可靠）。检测阈值即§1.1 的最小供水阈值——**失效与预警在同一时刻发生**（对应 `scada.detect_fault`）：

```
检出  ⟺  warning_enabled 且  p_muni < p_muni^trip                 (阈值判据, 检出后锁存)
预警送达电网时刻  t_warn = t_detect        (零时延: 送达=检出)
```
参数：`p_muni^trip = H_muni_min = 28 m`（正常约 32 m）。即供水失效判据与 ICS 预警判据是同一个阈值。

### 6.1a 预警触发时刻的选择（设计论证）

预警链路存在两种可能的**触发时刻**定义，本研究经论证采用**方案二**：

- **方案一（否决）：** 市政供水管网一旦发生任意故障（爆管/泵站跳闸/检修）即向电力中控发送预警。
- **方案二（采用）：** 仅当**为电厂机组配水的配水节点压头**跌破最小供水阈值（< 28 m）时，市政供水 ICS 才向电力系统 ICS 发出早期预警。

采用方案二、否决方案一的四点依据：

1. **可观测性与因果正确性。** 市政管网为多水源、环状/分区结构，某处故障**不必然**导致给电厂配水节点压头不足（网络可经其它水源/连通管自愈或隔离）。对电厂真正**可观测、可量化、且直接决定后果**的物理量是**配水节点压头**；方案二监测该量，信号明确可测；方案一监测的"故障发生"是位置与影响皆不确定的抽象事件。
2. **与参照文献严格对齐。** Yu et al. (Nat. Commun. 15:4714, 2024) 的触发点并非"天然气管网发生故障"，而是**终端/电厂进气口压力跌破保护阈值**，并自该时刻起算 ALP 与 AET/SAET。类比到本研究，正确触发点即**配水节点压头越过最小供水阈值**——也恰是**补水中断、可用储水量 ASW 开始净耗尽**的起点。方案一会打破此对应，使 AET/SAET 失去物理基准。
3. **避免误报的无谓主动控制成本。** 主动控制（受影响机组降出力 + 其余机组顶爬坡、动用备用）有再调度/非经济出力/备用消耗代价；方案一对每次市政故障（含大量从未真正威胁电厂的局部/瞬态故障）都触发，代价—收益关系失衡；方案二仅在真实且可量化的威胁出现时触发。
4. **时间零点自洽且可复现。** `H_muni_min = 28 m` 同时是失效判据（`make_flow→0`，补水停止）与 ICS 检出阈值，使"供水实际失效"与"预警发出"重合于同一瞬间，给 ASW/AET/SAET 一个干净、可复现、与文献一致的 t=0。方案一把检测与实际失效解耦，引入依赖故障位置与管网拓扑的**不确定提前量**，在本项目"无现场数据、按规范拟合"前提下不可控。

**关于分级（两级）预警的取舍。** 曾考虑一个折中方案：在压头进入预警带（如 30 m，尚未跌破 28 m）时先发**关注/提示级**信号（仅提升备用就绪度、不触发有约束控制），跌破 28 m 时再发**行动级**正式预警。经权衡，本研究**不引入分级预警**，理由：(a) 会把预警自变量由 WARN/NOWARN 二值变为多值，破坏本研究"有无预警"的干净对照设计；(b) 关注级带来的提前量取决于 32→28 m 的市政瞬态时长，在无现场数据下无法量化、无法复现，等于引入一个说不清的自由参数；(c) 单阈值触发逻辑链最短、假设最少、最易复现（奥卡姆剃刀）。分级预警仅在**将来取得真实市政管网瞬态数据**、或研究重心转向**预警系统本身的阈值整定与误报/漏报权衡**时才有数据支撑与研究价值，届时作为未来工作展开（见 §8/局限）。

### 6.2 有无预警两种情形

```
WARN   : 检出 → t_warn → 电网侧触发主动处置(§4: 备用预起机 + runback) → 少发功率/损失电量≈0
NOWARN : 不检测 → 被动 → 备用仅在跳机后起机 → 深度少发功率/损失电量
```

### 6.3 采样与归档

PLC 零阶保持采样（周期 sample_dt）；SCADA 告警分级（按集水池水位，仅监视）；全过程写 SQLite（传感器/执行器/告警/调度/预警/快照 6 表）。

## 7A. 早期预警指标与主动控制 LP（P6，对齐参照文献）

本节按参照文献 **Yu et al., Nat. Commun. 15:4714 (2024)（孙宏斌院士团队）** 的"气-电早期预警"方法，将物理量由天然气替换为冷却水，形式化预警指标并用线性规划求解主动控制。**潮流全程采用直流潮流(DC-PF/PTDF)，备用体系为两级（旋转备用 + 慢起机备用）。**

### 7A.1 早期预警指标（气→水类比）

| 文献（气） | 本项目（水） | 定义 |
|---|---|---|
| ALP 可用管存 | **ASW 可用储水量** | 跳泵前可用的补水箱+集水池水量 |
| AET 可用逃逸时间 | AET | 受影响机组进入高背压/跳泵保护前的剩余时间 |
| SAET 静态 AET | SAET | 故障时刻的初始 AET（缓冲窗口）|

```
ASW0 = A_tank·(H_tank,0 − H_tank^min) + A_pool·(H_pool,0 − H_sub^min)      (m³)
AET(ramp)  = 受影响机组按降出力速率 ramp 运行时的跳机时刻 (由 §1–§2 前向积分)
SAET       = AET(ramp = 0)   （恒定额定出力下的跳机时刻）
```

**关键性质（与文献一致）：** 受影响机组降出力越快，凝汽器热负荷越低、背压上升越缓，机组可在 ASW 耗尽前**主动停机**而非被强制跳机；存在**临界降出力速率**使运行时间最长。对应 `warning_indicators.py`。

### 7A.2 主动控制线性规划（PA / SP / DP）

理论：**线性规划(LP)**，目标为最小化控制期总能量缺额（对应 `proactive_lp.py`）：

```
决策变量:  P_g[i,t] (各机组各时步出力),  d[t] (功率缺额松弛),  o[ℓ,t] (线路过载松弛)
目标:      min  Σ_t d[t]·Δt  +  w · Σ_{ℓ,t} o[ℓ,t]              (w=过载惩罚权重)

约束:
 (功率平衡)  Σ_i P_g[i,t] + d[t] = P_load^total                        ∀t
 (机组容量)  0 ≤ P_g[i,t] ≤ P_max,i                                    (其余机组)
             0 ≤ P_g[i,t] ≤ P_avail,i(t)                               (受影响机组, 见下)
 (爬坡率)    |P_g[i,t] − P_g[i,t−1]| ≤ R_i·Δt                          (其余机组)
 (直流潮流)  |PTDF_ℓ·(A_g·P_g,t − P_d)| ≤ rate_ℓ + o[ℓ,t]              ∀ℓ,t
 (失效末端)  受影响机组 i∈SIG:  P_g[i,t] = 0  当 t ≥ T_i               (控制时间末出力为零)
```

**受影响机组可用出力轨迹 P_avail,i(t)：**
```
SP/DP:  P_avail,i(t) = P_g0,i · max(0, 1 − t/T_i)          (主动软着陆, 线性降到零)
PA:     P_avail,i(t) = P_g0,i · [t < t_trip,i]             (被动: 按水力跳机时刻突降)
```

**被动因果约束（PA 与主动的本质区别）：** 被动模式下，其余机组在受影响机组**跳机前不得预升出力**：
```
PA:  P_g[i,t] ≤ P_g0,i     对所有其余机组 i, 当 t < t_firsttrip
```
即被动只能在缺额真正出现后才动用备用；主动则从预警时刻(t=0)即可提前爬坡。

### 7A.3 三种控制策略（对齐文献 Fig.6）

```
PA 被动控制:      受影响机组按水力轨迹突然跳机; 备用事后响应(受爬坡限制)
SP 静态主动控制:  T_i = SAET_i, 在静态逃逸时间内降到零; 备用从 t=0 预爬坡
DP 动态主动控制:  T_i = α·SAET_i (α>1), 迭代延长控制时间, 动用更多备用+储水
```
参数：爬坡率 `R_i ≈ 0.01·P_max,i /min`（典型），时间比 `α=1.5`，过载惩罚 `w=5`。
结果（母线 89/80/10，同源同位置）：最大功率缺额 PA 343.3 → SP 0.0 → DP 0.0 MW（与文献 PA>SP>DP 一致）。

### 7A.4 取水节点位置的敏感性（回应"失压时刻依赖取水位置"）

**疑问（审阅提出）：** 不同 junction 节点在市政水源停供后失压时刻差异极大，故选不同节点为电厂供冷却水，"开始影响机组的时刻"自然不同。对应 `src/03_proactive_control/node_sensitivity.py` 与 `src/00_muni_wdn/saet_distribution.py`。

**两级缓冲（务必区分）：**
```
市政级: 水源停供 → 取水节点跌破28m。时长 t_muni(节点), 强依赖节点位置(小时级)
        D-town 全网分布: P10/P50/P90 = 3.8/9.8/17.0 h; 28% 节点长时间不失压
冷却级: 取水失效 → 机组跳机。时长 = 冷却 SAET(~90~125 min), 电厂内部属性, 与节点无关
```
节点选择影响的是**第 1 级**"开始影响机组的时刻"（危机起点），而非第 2 级冷却缓冲窗口。

**LP 中的形式化（`muni_offset_min`）：** 为受影响机组 i 引入市政失压偏移 `τ_i`（其取水节点跌破 28 m 的时刻），受影响机组可用出力轨迹改为：
```
市政失压前 (t < τ_i):   P_avail,i(t) = P_g0,i           (配水压力正常, 未进入危机)
市政失压后 (t ≥ τ_i):   按 §7A.2 的 SP/DP 软着陆或 PA 跳机, 自 τ_i 起算
```
默认 `τ_i = 0`（同源同位置，同时故障），即退化为 §7A.2/§7A.3 的原模型。

**两种取水布置对比（三厂 89/80/10）：**
| 布置 | 市政偏移 τ (h) | PA 最大缺额 | SP/DP 最大缺额 |
|---|---|---|---|
| CO 同源同位置 | [0,0,0] | 343.3 MW | 0 / 0 MW |
| DISP 分散取水 | [3.8,9.8,17.0] | 314.9 MW | 0 / 0 MW |

**机理结论：**
1. **被动(PA) 受取水位置显著影响：** 同源同位置各机组缺额脉冲**时间重叠→峰值叠加**(343 MW)；分散取水（偏移小时级 ≫ 冷却窗口 ~2 h）缺额脉冲**时间分离→峰值不叠加**(315 MW，=最严重单机)。
2. **主动(SP/DP) 对取水位置稳健：** 各机组自其市政失压时刻起有冷却 SAET 窗口做软着陆（窗口与节点无关），逐台均可消除缺额；市政失压先后仅把危机在时间轴上平移/错开。
3. **方法（物理正确且计算可行）：** CO 用联合 LP 求解；DISP 因危机时间隔离，等价于独立单机 LP，系统峰值取 max（不叠加）、能量取 sum（守恒），避免 25 h 长时域巨型 LP。
