# 参数拟合与来源登记表

**背景：** 本研究无现场数据，仅有 IEEE 118 稳态数据。所有动态/热力/水力参数依据**国家/国际标准 + 典型参数库**，并按**机组额定容量与实际出力**拟合赋值。本表统一登记参数取值与出处，保证可追溯、可复现。

## 1. 拟合总原则
1. **容量分档：** 按发电机额定容量 `Pmax`（来自 `ieee118_dc/gen.csv`）分档赋典型参数。
2. **出力标定：** 以实际出力 `Pg` 与额定 `Pmax` 之比对可缩放参数（惯性、热负荷、循环水量等）做插值/标定。
3. **额定工况自洽：** 在额定出力下反推设计背压、设计循环水量等，保证稳态基准点物理一致。
4. **来源可追溯：** 每个参数注明标准号/文献/参数库。

## 5. 参照标准
- **GB/T 50102**《工业循环水冷却设计规范》——循环水量/温升、冷却塔冷幅、蒸发/排污/风吹损失
- **DL/T 5339**《火力发电厂水工设计规范》——集水池/吸水井容积与停留时间
- **HEI** Standards for Steam Surface Condensers；**ASME PTC 12.2**——凝汽器换热/性能
- **IEEE Std 421.5**——励磁/调速模型（如后续引入机电动态）
- **WECC / CIGRE** 发电机动态典型参数库
